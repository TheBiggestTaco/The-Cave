# The Cave — Generation 0

A standalone, browser-playable reconstruction of the first Cave experience. The original ChatGPT Site is untouched.

## Play
Open index.html in a browser, or deploy the repository with GitHub Pages.

Move with WASD, arrow keys, touch directional buttons, or an Xbox-compatible controller. Interact with E, Space, the on-screen button, or controller A. Activate four points to form a room, then exit to discover the next chamber.

## Views
- Play: the first playable room-building loop.
- Rule Map: rules behind points, lines, rooms, and corridors.
- Stems: starting point for future version branching.

Save and Load use browser localStorage. This is a new prototype, not a copy of the inaccessible original source.
